# Projeto Web Simples

Este projeto é uma aplicação web simples que solicita ao usuário dois números e exibe a soma deles ao clicar em um botão.

## Estrutura do Projeto

O projeto possui os seguintes arquivos:

- `src/index.html`: A página principal que contém a estrutura HTML para solicitar os números e um botão para mostrar a soma.
- `src/styles.css`: O arquivo de estilos CSS que define a aparência da página.
- `src/script.js`: O arquivo JavaScript que contém a lógica para calcular a soma e manipular o DOM.

## Como Executar o Projeto

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra o arquivo `src/index.html` em um navegador web.
3. Insira dois números nos campos fornecidos e clique no botão para ver a soma.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
